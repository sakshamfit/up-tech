# up-tech

**Made by Saksham.**

An unofficial, responsive website about Telangana Technology Services (TGTS): government technology, procurement, consultancy and e-governance. The site is a buildless static site; all of it lives in `dist/`.

## Run locally

No build step or dependencies are needed. Open `dist/index.html` in a browser, or serve the folder:

```bash
cd dist && python3 -m http.server 8080
```

Then visit http://localhost:8080.

## Features

- Responsive layouts for desktop, tablet and mobile
- Sticky navigation and a compact mobile menu
- Government identity masthead with leadership portraits
- Continuously scrolling client logo marquee, with pause and reduced-motion controls
- Technology, cybersecurity and careers stories with photographs
- Expandable service directory with a photograph for every service
- Local search with service deep links
- Keyboard-accessible resource tabs and modal dialogs
- Higher contrast, text size and reduced motion controls
- Contact form that prepares an email draft; nothing is submitted or stored
- Related links strip with government portal logos
- Footer map with location details and directions
- Locally hosted photographs and font

## Content and disclaimer

This is an unofficial website. It is not an official TGTS or Government of Telangana service or application channel. For official information, RTI applications, tenders and vacancies, use the official portals listed in the site and in `CREDITS.md`.

Factual content is taken from official Telangana sources; see `CREDITS.md` for each source, photograph licence and logo origin. Photographs of technology, infrastructure and workplaces are illustrative unless a location is identified. The Secretariat photograph is identified as such and is not represented as the TGTS office.
